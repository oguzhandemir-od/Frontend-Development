# 🎨 Frontend Development - Geliştirici Kütüphanesi

Bu depo; HTML5, CSS3, Modern Bootstrap ve JavaScript (ES6+) ekosisteminde geliştirdiğim web arayüzlerini, interaktif workshop projelerini ve eğitim çıktılarımı tek bir çatı altında toplayan **ana frontend kütüphanemdir**.

Projelerin tarayıcı tarafındaki gelişimini, arayüz pratiklerini ve dinamik script çözümlerini merkezi bir yapıda takip etmek amacıyla **Monorepo** mimarisiyle tasarlanmıştır.

## 📂 Kütüphane Yapısı

Kütüphane içerisindeki klasörlere dair bilgi:

* [CodingLab](/CodingLab) - YouTube ve CodingLab platformu üzerindeki video serilerinden esinlenerek geliştirilmiş; modern CSS teknikleri, responsive tasarımlar ve interaktif JavaScript bileşenleri içeren pratik projeler.

* [TechCareer](/TechCareer) - Techcareer bünyesinde katıldığım, temel web teknolojilerinden başlayarak Bootstrap dinamiklerine ve JavaScript workshop projelerine uzanan yoğunlaştırılmış eğitim ve ödev çıktıları.

* [Udemy](/Udemy) - Udemy üzerindeki eğitmenlerden aldığım, modern JavaScript (ES6+), DOM manipülasyonu, asenkron programlama ve web geliştirme temellerini içeren kapsamlı kurs projeleri.

## 🛠️ Kullanılan Teknolojiler & Yetkinlikler

* **Core:** HTML, CSS, Modern JavaScript
* **Frameworks & Libraries:** Bootstrap
* **Concepts:** Responsive Web Design (Mobil Uyumlu Tasarım), DOM Manipülasyonu, Flexbox/Grid Sistemleri, API & Asenkron Pratikler
